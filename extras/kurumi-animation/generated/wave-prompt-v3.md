# 狂三挥手关键帧提示词（v3）

这些提示词整理自本轮素材生成要求，使用 `reference/idle-approved.png` 作为角色外观与比例参考。每张图单独生成，再按姿势顺序组成动作；不使用大肥鱼角色图帧。

## 共用主提示词

> 以已批准的时崎狂三 Q 版透明立绘作为唯一角色参考，绘制一张连续桌宠动画中的单独关键帧。保持参考图的同一张脸、柔和微笑、左红眼右金眼、黑色双马尾、红黑发饰、黑红哥特洛丽塔连衣裙、独立长袖、束腰蝴蝶结、多层裙摆、短腿和黑色蝴蝶结鞋。严格保持约两头身比例、头身大小、服装长度、镜头角度、光线与精致柔和的动画线稿。角色完整入镜、居中、正面略微转身，脚底保持在画面同一高度，画布固定为 1377×1142，透明背景。只改变本帧指定的动作；不要重设计角色，不要改变裙长、头发体积、身体比例或人物尺寸。不要添加动物尾巴、道具、文字、背景、地面、阴影、边框或其他人物。

## 姿势差异

1. **起势 / `wave-anticipation-v1.png`**：身体轻轻预备，画面左侧的手从裙边向上抬到胸口附近，手指自然微弯；另一只手仍靠近裙边，表情含笑。
2. **挥手主体 / `wave-intermediate-v1.png`**：同一只手继续抬到脸旁，手肘自然弯曲，掌心朝向观众，手指舒展；肩膀与身体轻微转向。
3. **挥手主体 / `wave-intermediate-v2.png`**：保持同一姿势和人物尺寸，只让手腕、掌心角度及手指方向发生小幅变化，表现挥手回摆。
4. **收势 / `wave-recovery-v1.png`**：手腕回正，手掌放松，从脸旁缓缓降到肩部附近，肩膀和身体开始回正。
5. **放手 / `wave-lowered-v1.png`**：手臂自然落回身体一侧，表情回到待机微笑；人物尺寸、脚底位置与参考图一致。

## 验收约束

- 从待机到挥手再返回待机，裙摆长度、鞋底高度、头部大小和双马尾造型不能突然变化。
- 动作按“起势 → 连续挥动 → 收势 → 待机”播放，最后一帧使用批准的原始待机立绘。
- 输出必须是单角色全身透明 PNG。任何越界、截肢、尾巴、文字、背景或比例明显不一致的画面都不进入安装包。
