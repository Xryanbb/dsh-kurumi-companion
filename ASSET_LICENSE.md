# Artwork and animation assets

The Kurumi illustrations, transparent animation frames, and face/hair textures in this repository are generated fan art based on the user-approved chibi reference. The v3 Blender geometry is newly modeled for this companion project and uses the existing v2 face texture. Tokisaki Kurumi and *Date A Live* belong to their respective rights holders. These assets are unofficial, are not endorsed by those rights holders, and are not covered by the code's MIT license.

The assets are shared for personal, non-commercial use in this DSH companion project. Do not claim ownership of the character or use the assets commercially. If a rights holder requests removal, the artwork should be removed from distributions.
